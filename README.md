# MSLU App
Приложение для доступа студентов Московского государственного лингвистического университета.


## Основные понятия и термины

- **Успеваемость**: Данные об оценочных ведомостях, зачетах и экзаменах студента, загружаемые из личного кабинета.

- **Расписание**: занятия в сетке (лекции, семинары, лабораторные) с привязкой к дате, времени, номеру группы и преподавателю.

- **Авторизация**: Процесс аутентификации пользователя через корпоративную учетную запись МГЛУ.

- **Аудитории и корпуса**: Пространственные объекты университета, используемые в модуле навигации.

- **Уведомления**: Системные события и оповещения об изменениях в графике учебного процесса.

### Аннотация
  Приложение **MSLU App** представляет собой мобильный клиент для студентов и преподавателей Московского государственного лингвистического университета (МГЛУ). Проект предназначен для получения информации о расписании занятий и интеграции с внутренними сервисами вуза через API.

## Основные возможности

- Просмотр расписания занятий (день/неделя/месяц)
- Просмотр успеваемости (зачетной книжки)
- Просмотр профиля студента (личные данные, приказы и тд)
- Просмотр заметок (ДЗ) с напоминаниями о дедлайнах
- Работа без интернета — данные всегда под рукой

### 1. Как работает авторизация клиента?
Студент входит по логину и паролю один раз. Дальше приложение само поддерживает сессию активной до 30 дней — не нужно логиниться заново при каждом открытии.

- **Один вход — постоянный доступ.** После первого входа приложение помнит пользователя и открывается сразу на главном экране.
- **Незаметное обновление сессии.** Если сессия истекает, приложение обновляет её в фоне — студент не видит ни экрана логина, ни ошибок, ни задержек.
- **Безопасный логин по желанию.** Опционально можно подключить двухфакторную аутентификацию (код из приложения-аутентификатора) для дополнительной защиты аккаунта.
- **Автоматический выход при компрометации.** Если кто-то попытается использовать старую, уже недействительную сессию — она отзывается, и потребуется повторный вход.

### 2. Возможности домашнего экрана
#### Просмотр ключевой информации
- **Приветствие**: Отображается имя пользователя и номер группы
- **Текущая дата**: Показывает день недели и число
- **Учебная неделя**: Индикатор «Четная» или «Нечетная» (система чередования расписания в вузе)
- **Локация**: Основной корпус, где проходят занятия сегодня

#### Навигация по профилю
- **Тап по аватару/имени**: Переход на полный экран профиля с детальной информацией о студенте
- **Просмотр группы**: Отображается номер группы (например, «ИИН 1-24-1»)

#### Управление расписанием
- **Текущая пара**: Если занятие идёт прямо сейчас, показывается карточка с предметом, преподавателем, корпусом и аудиторией
- **Следующая пара**: Если текущей пары нет, отображается информация о ближайшем занятии с обратным отсчётом («Через 45 минут»)
- **Список пар на сегодня**: Хронологический список всех оставшихся занятий с временем начала, предметом, типом (лекция/семинар/практика), преподавателем и аудиторией
- **Тап по паре**: Переход к детальной информации о занятии
- **Принудительное обновление**: Кнопка обновления для синхронизации расписания с сервером вручную
- **Пустое состояние**: Если пар нет (каникулы, выходной), отображается дружелюбное сообщение

#### Отслеживание успеваемости
- **Тап по виджету**: Переход в полный раздел успеваемости с детализацией по предметам

#### Секция заметок (ДЗ)
- **Преподаватель может ставить заметку (ДЗ) на выбранную группу**. ?
- **Студент сам ставит заметку (ДЗ)**.
- **Счётчик заметок (ДЗ)**: Отображается количество несделанных (домашних заданий).
- **Цветовая индикация срочности**:
  - Зелёный: дедлайн более чем через 3 дня
  - Жёлтый: дедлайн через 1–2 дня
  - Красный: дедлайн сегодня
- **Тап по виджету**: Переход к списку заметок (домашних заданий).

#### Уведомления
- **Колокольчик**: Иконка с непрочитанных уведомлений.
- **Типы уведомлений**: Замена пары, отмена занятия, новая оценка, заметка (домашнее задание от преподавателя)
- **Тап по колокольчику**: Переход к списку уведомлений

#### Нижняя навигация
Четыре основные вкладки для быстрого переключения между разделами:
- **Дом**: Текущий экран с агрегированной информацией
- **Календарь**: Полное расписание с видами «День», «Неделя», «Месяц» 
- **Профиль**: Данные студента, настройки, выход из аккаунта

#### Работа без интернета
- Все данные отображаются из локального кэша, если нет подключения к интернету.
- Автоматическая синхронизация при восстановлении соединения.
- Индикатор offline-режима в верхней части экрана.

### 3. Возможности профиля студента

- Личные данные: ФИО, фото, группа, курс, специальность.
- Просмотр и редактирование контактных данных.
- Настройки уведомлений — какие события присылать push-уведомлением, а какие нет.
- Управление безопасностью аккаунта: смена пароля.
- Выход из аккаунта на текущем устройстве.
- Заказать и просмотреть справку об обучении.

### 4. Возможности расписания занятий

- Просмотр расписания по дням, неделям и месяцам.
- Переключение между учебными периодами (четность/нечетность, семестр).
- просмотр Карточка занятия: предмет, тип (лекция/семинар/практика), время, аудитория, корпус, преподаватель, ссылка на дистанционное занятие.
- Визуальное выделение изменений — перенос/замена пары, замены аудитории или преподавателя видны сразу.
- Работает офлайн — расписание доступно даже без интернета, обновляется автоматически при подключении к сети.
- Быстрый переход к деталям пары (если добавлены материалы или дополнительная информация).

### 5. Возможности успеваемости (уточняем что это во введении в терминах)

- Оценки по всем предметам за текущий семестр.
- История оценок по каждому предмету в хронологическом порядке за два семестра.
- Уведомление о появлении новой оценки.
- Доступно офлайн — последние данные всегда под рукой, даже без сети.
